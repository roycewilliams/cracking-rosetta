Generated by tools/render.pl. Also available as ROSETTA.md and rosetta.csv. Every row has a permalink — the # that appears when you hover it. What is missing, and what fixing it costs, is in GAPS.md; what is known to be doubtful is in OPEN-QUESTIONS.md; what checking all this turned up about the upstream documents is in UPSTREAM-FINDINGS.md. A gap is not a claim that the tool cannot do it — it means nobody has said. "Cost" is hashcat's own fast/slow split with John's tunable cost under it; "Shape" is how long the hash string is, then which tools salt it (hc hashcat, jo John, mx mdxfind) and how many hashes deep the construction goes. A length followed by ? rests on a single vector and ! means the vectors on that row disagree. The salt marks are per tool and never merged, because an entry can name a hashcat mode that takes no salt and an mdxfind type that does. "Same as" names another row that is the same computation, and why both rows exist; the full typed edges are in rosetta.json. Alec Muffett's Crack is covered separately in CRACK.md. Built on the community spreadsheet this replaces — years of work by multiple HashMob members — and on Cynosure Prime's verified mdxfind and hashpipe data. Merged ids, kept so old links resolve: hav256 → HAVAL-256-3; md5md5uc → md5(strtoupper(md5($pass))); ntlm-plain-md4-utf16-le-plain → md4(utf16($plain)); panama → Panama; ripemd320 → ripemd320; sha1-md5-md5-pass-salt → sha1(md5($pass).$salt); sha224 → Raw-SHA224; sha384 → Raw-SHA384; sm3 → ShangMi 3.
