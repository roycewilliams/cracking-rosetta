A finding lands here when this repository measures a document to state
something the tool does not do. It leaves when upstream changes the document.
Where the claim can be tested against a vendored file it is *also* a record in
`data/upstream-disagreements.yaml`, executed by `tools/check-upstream.pl` on
every build, and that record is what notices the fix -- this page checks only
that our own side still makes the claim, so the pairing is what keeps it from
going quietly out of date.

To report one, open an issue or a pull request against
`data/upstream-findings.yaml`. A finding needs what was measured, what the
document states, and how the two were compared.
